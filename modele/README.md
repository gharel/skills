# Modèle de skill

Copiez ce dossier dans `skills/<catégorie>/<nom-du-skill>/`, renommez `SKILL.md.modele` en `SKILL.md` (le suffixe évite que les outils d’installation prennent le modèle pour un vrai skill), changez `name` (identique au nom du dossier), puis suivez la section « Ajouter un skill » d'[AGENTS.md](../AGENTS.md). Ce fichier README est à supprimer dans la copie.
