Installer et mettre à jour

Choisissez votre assistant. Pour mettre à jour, on refait la même opération : la nouvelle version remplace l’ancienne. Options, mise à jour automatique, usage et dépannage : voir la documentation.

Claude (claude.ai et Claude Desktop)

  1. Téléchargez le skill (bouton Télécharger le skill de sa carte).
  2. Dans Claude, ouvrez Paramètres > Capacités, section Skills, puis Importer un skill et choisissez le fichier .zip.
  3. Activez le skill. Claude l’utilise dès qu’une demande le concerne.

Mise à jour : supprimez l’ancienne version du skill, puis importez le nouveau .zip. Pensez à désactiver les anciens skills plan-creator, support-creator et qcm-creator, remplacés par les skills Skazy Formation.

ChatGPT

Avec les Skills de ChatGPT : importez le fichier .zip du skill depuis la gestion des skills de votre compte. ChatGPT l’utilise dès qu’une demande le concerne.

Sinon, avec un GPT personnalisé ou un projet :

  1. Créez un GPT (ou un projet) et collez ses instructions courtes (bouton Copier les instructions de la carte).
  2. Ajoutez en fichiers de connaissance la version un fichier (.md) et le contenu du .zip (scripts et charte).
  3. Activez l’interpréteur de code pour produire les fichiers.

Mise à jour : remplacez les fichiers par ceux de la nouvelle version.

Claude Code (et Cowork)

Ajoutez le dépôt comme place de marché de plugins, une seule fois :

/plugin marketplace add gharel/skills

Puis installez une catégorie de skills (Skazy Formation, UNC) :

/plugin install skazy-formation@gharel-skills
/plugin install unc@gharel-skills

Mise à jour : activez la mise à jour automatique de la place de marché gharel-skills dans /plugin, onglet Marketplaces, ou lancez /plugin marketplace update gharel-skills. Avec le plugin installé, la commande de l’onglet suivant ne double pas les skills dans Claude Code.

Codex, Gemini CLI, Cursor, GitHub Copilot, OpenCode…

Une commande installe chaque skill une seule fois, dans ~/.agents/skills : Codex, Gemini CLI, GitHub Copilot, Cursor et OpenCode lisent ce dossier. Claude Code et Windsurf y sont reliés par un lien.

Windows (PowerShell) :

irm https://gharel.github.io/skills/installer.ps1 | iex

macOS, Linux et WSL (qui équipe aussi les assistants de Windows) :

curl -fsSL https://gharel.github.io/skills/installer.sh | sh

Mise à jour : relancez la commande. Seuls les skills changés sont téléchargés, et ceux retirés du catalogue sont supprimés. Pour une mise à jour automatique chaque jour (tâche planifiée, launchd ou systemd) :

$env:SKILLS_AUTO='1'; irm https://gharel.github.io/skills/installer.ps1 | iex
curl -fsSL https://gharel.github.io/skills/installer.sh | SKILLS_AUTO=1 sh

Options, retenues pour les mises à jour suivantes : SKILLS_CATEGORIE=pro (une catégorie), SKILLS=skazy-quiz (certains skills, dont ceux marqués « Sur demande »), SKILLS_ACTION=desinstaller (tout retirer, sauvegardes restaurées). Un skill personnel du même nom est sauvegardé, jamais écrasé. Avec Node.js, npx skills add gharel/skills -g fonctionne aussi.

Gemini, Mistral Le Chat, Copilot, Perplexity…

  1. Créez un Gem, un agent ou un espace, et collez les instructions courtes du skill.
  2. Ajoutez en documents de référence la version un fichier (.md) et le contenu du .zip (scripts et charte).
  3. Activez l’exécution de code : l’assistant lance les scripts du skill pour produire les fichiers HTML, DOCX, PPTX, Kahoot ou Google Forms.

Versions et nouveautés

Chaque skill porte un numéro de version (affiché sur sa carte). Une carte marquée Nouvelle version a changé depuis votre dernière visite. Le détail des changements est dans le journal des versions.

Un skill, c’est quoi ?

Un dossier au format ouvert Agent Skills : un fichier SKILL.md (les consignes), des références, des modèles et des scripts. L’assistant ne le charge que lorsque la demande le concerne.
