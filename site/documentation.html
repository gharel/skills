Installer et utiliser les skills

Équiper votre assistant, le tenir à jour et lui faire produire vos documents : plan, support, quiz ou grille de notation. Valable pour Claude, ChatGPT et les assistants en ligne de commande, sous Windows, macOS, Linux et WSL.

Par où commencer

Repérez votre assistant, puis suivez la section indiquée.

Assistant Installation Mise à jour
Claude.ai, Claude Desktop Importer le .zip Réimporter le .zip
ChatGPT Importer le .zip, ou un GPT avec la version un fichier Réimporter
Claude Code, Cowork Plugin de la place de marché Automatique
Codex, Gemini CLI, GitHub Copilot, Cursor, OpenCode, Windsurf Une commande Relancer la commande, ou chaque jour automatiquement
Gemini, Mistral Le Chat, Perplexity… Instructions courtes et fichiers Remplacer les fichiers

Claude et ChatGPT

Claude.ai et Claude Desktop

  1. Sur le catalogue, cliquez sur Télécharger le skill pour obtenir son fichier .zip.
  2. Dans Claude, ouvrez Paramètres > Capacités. Vérifiez que l’exécution de code est activée : les skills en ont besoin pour produire les fichiers.
  3. Section Skills, choisissez Importer un skill, puis le fichier .zip. Activez le skill.

Pour une nouvelle version, supprimez l’ancienne puis importez le nouveau .zip. Désactivez les anciens skills plan-creator, support-creator et qcm-creator : les skills Skazy Formation les remplacent.

ChatGPT

Importez le fichier .zip depuis la gestion des skills de votre compte. Sans les Skills, passez par un GPT personnalisé ou un projet :

  1. Collez les instructions courtes du skill (bouton Copier les instructions de sa carte).
  2. Ajoutez en fichiers de connaissance la version un fichier (.md) et le contenu du .zip : scripts et charte.
  3. Activez l’interpréteur de code.

Claude Code

Ajoutez le dépôt comme place de marché, une seule fois :

/plugin marketplace add gharel/skills

Puis installez les catégories qui vous servent :

/plugin install skazy-formation@gharel-skills
/plugin install unc@gharel-skills

Pour les mises à jour, ouvrez /plugin, onglet Marketplaces, et activez la mise à jour automatique de gharel-skills. À défaut : /plugin marketplace update gharel-skills. Les mêmes plugins servent dans Cowork.

Avec le plugin installé, la commande ne pose aucun lien pour Claude Code : les skills n’apparaissent pas deux fois.

Assistants en ligne de commande

Une commande installe tous les skills pour Codex, Gemini CLI, GitHub Copilot, Cursor, OpenCode, Windsurf et Claude Code. Elle ne demande ni Node.js ni droits administrateur.

Windows

Dans PowerShell (5.1, fourni avec Windows, ou 7) :

irm https://gharel.github.io/skills/installer.ps1 | iex

macOS et Linux

Dans un terminal :

curl -fsSL https://gharel.github.io/skills/installer.sh | sh

Il faut curl (ou wget) et unzip (ou python3), présents sur la plupart des systèmes.

WSL

Lancez la commande curl dans votre distribution. Elle équipe d’abord les assistants lancés dans WSL, puis ceux de Windows (Claude Desktop, Cursor…) par powershell.exe. Pour équiper WSL seul :

curl -fsSL https://gharel.github.io/skills/installer.sh | SKILLS_WINDOWS=0 sh

Git Bash, MSYS ou Cygwin

La commande curl passe la main à PowerShell : le résultat est le même que sous Windows.

Ouvrez ensuite une nouvelle session de votre assistant pour qu’il charge les skills. Claude Code les voit aussitôt.

Autres assistants

Gemini, Mistral Le Chat, Copilot, Perplexity et les autres n’importent pas de dossier de skill. Créez un Gem, un agent ou un espace :

  1. collez les instructions courtes du skill ;
  2. ajoutez en documents la version un fichier (.md) et le contenu du .zip ;
  3. activez l’exécution de code, si l’assistant la propose.

Sans exécution de code, l’assistant vous donne le JSON et la commande pour produire les fichiers sur votre poste (voir Utiliser les skills).

Ce que fait la commande

  1. Elle lit le catalogue publié sur ce site. Seules les versions qui ont passé les contrôles y figurent.
  2. Elle télécharge les skills nouveaux ou changés, et seulement eux.
  3. Elle range chaque skill une seule fois, dans ~/.agents/skills.
  4. Elle relie ce dossier aux assistants qui ne le lisent pas.
  5. Elle note ce qu’elle a installé dans un manifeste, ~/.agents/.gharel-skills/manifeste.tsv.
Assistant Dossier lu Ce que pose la commande
Codex, Gemini CLI, GitHub Copilot, Cursor, OpenCode ~/.agents/skills Rien de plus : ils lisent les skills à la source.
Claude Code ~/.claude/skills Un lien par skill (une jonction sous Windows), sauf si le plugin est installé.
Windsurf ~/.codeium/windsurf/skills Un lien par skill.

Sous Windows, ~ désigne votre dossier personnel, C:\Users\<nom>.

Vos propres skills

La commande ne touche qu’aux dossiers qu’elle a installés. Si un de vos skills porte le même nom qu’un des nôtres, elle le déplace dans ~/.agents/.gharel-skills/sauvegardes avant d’installer le sien. La désinstallation le remet à sa place.

Les anciennes versions de la commande copiaient les skills dans chaque dossier d’assistant : ces copies en double sont retirées au premier passage.

Options

Les options sont des variables d’environnement, posées avant la commande. La sélection est retenue : les mises à jour suivantes la gardent.

Variable Valeur Effet
SKILLS Noms séparés par des virgules, ou tout Seulement ces skills, y compris ceux marqués « Sur demande ». tout revient à la sélection par défaut.
SKILLS_CATEGORIE pro, unc, perso, ou tout Seulement ces catégories (plusieurs, séparées par des virgules).
SKILLS_AUTO 1 ou 0 Inscrit ou retire la mise à jour quotidienne.
SKILLS_ACTION desinstaller Retire tout ce que la commande a installé.
SKILLS_DOSSIER Un chemin Installe dans ce seul dossier, sans lien ni mise à jour automatique.
SKILLS_WINDOWS 0 Sous WSL, n’équipe pas Windows.

Par exemple, pour les seuls skills Skazy Formation, sous Windows :

$env:SKILLS_CATEGORIE='pro'; irm https://gharel.github.io/skills/installer.ps1 | iex

Sous macOS, Linux ou WSL :

curl -fsSL https://gharel.github.io/skills/installer.sh | SKILLS_CATEGORIE=pro sh

Dans PowerShell, une variable reste posée jusqu’à la fermeture de la fenêtre. Retirez SKILLS_ACTION après une désinstallation : Remove-Item env:SKILLS_ACTION.

Mettre à jour

Assistants en ligne de commande

Relancez la commande d’installation. Son bilan marque chaque skill : + nouveau, ^ mis à jour (ancienne et nouvelle version), = déjà à jour, - retiré.

Pour que la mise à jour se fasse seule, chaque jour, lancez une fois :

$env:SKILLS_AUTO='1'; irm https://gharel.github.io/skills/installer.ps1 | iex
curl -fsSL https://gharel.github.io/skills/installer.sh | SKILLS_AUTO=1 sh
Système Mécanisme Vérifier
Windows Tâche planifiée gharel-skills, chaque jour à 9 h Get-ScheduledTask gharel-skills
macOS LaunchAgent nc.skazy.gharel-skills, chaque jour à 9 h launchctl list | grep gharel
Linux, WSL Timer systemd de l’utilisateur, sinon crontab systemctl --user list-timers gharel-skills.timer

Un ordinateur éteint à l’heure prévue fait la mise à jour à son prochain démarrage. SKILLS_AUTO=0 retire la tâche.

Claude Code, Claude.ai et ChatGPT

Claude Code suit la place de marché (voir Claude Code). Pour Claude.ai et ChatGPT, réimportez le .zip. Le catalogue signale par un badge Nouvelle version les skills changés depuis votre dernière visite, et le journal des versions dit ce qui a changé.

Désinstaller

$env:SKILLS_ACTION='desinstaller'; irm https://gharel.github.io/skills/installer.ps1 | iex
curl -fsSL https://gharel.github.io/skills/installer.sh | SKILLS_ACTION=desinstaller sh

La commande retire les skills, les liens, le manifeste et la tâche planifiée, puis remet en place vos skills sauvegardés. Dans Claude Code : /plugin uninstall skazy-formation@gharel-skills. Dans Claude.ai ou ChatGPT, supprimez le skill depuis les paramètres.

Utiliser les skills

Il n’y a pas de commande à retenir : décrivez ce que vous voulez. L’assistant connaît la description de chaque skill et charge celui qui correspond à votre demande. Pour être sûr qu’il le prenne, nommez-le : « avec le skill skazy-quiz ».

La chaîne Skazy Formation

Les trois skills Pro s’enchaînent. Chacun accepte le JSON produit par le précédent (plan.json, puis support.json) : gardez-le, il évite de tout réexpliquer.

  1. 1. Plan de formation

    « Fais un plan de formation Power BI pour débutants, sur deux jours. »

    Une fiche programme A4 en HTML (à imprimer en PDF) et en DOCX (Word, Google Docs), plus plan.json.

  2. 2. Support de formation

    « Crée le support de formation de ce plan. »

    Joignez plan.json ou le DOCX. Vous obtenez un diaporama HTML à projeter et un PPTX (PowerPoint, Google Slides), avec les notes formateur.

  3. 3. Quiz

    « Prépare un quiz de 15 questions sur ce support, pour Kahoot. »

    Un fichier Kahoot (.xlsx), un script Google Forms, un lien vers le Quiz Skazy et un corrigé. Le quiz ne reprend que ce que dit le support.

UNC : notation des étudiants

« Corrige le TP 2 : voici l’énoncé, le barème et les mails des étudiants. »

Une note justifiée par critère, un onglet par étudiant (Google Sheets ou .xlsx) et une estimation indicative de l’usage de l’IA, à relire avant de communiquer les notes.

Comment les fichiers sont produits

Le skill fait écrire à l’assistant un JSON documenté. Un script Python le contrôle et le transforme en fichiers aux couleurs de la charte. Si l’assistant exécute du Python (Claude, ChatGPT, Codex, Claude Code…), vous recevez directement les fichiers. Sinon, il vous donne le JSON et la commande à lancer sur votre poste, par exemple :

pip install python-docx python-pptx openpyxl pillow
python scripts/rendre_plan.py plan.json --sortie sorties

Pour de bons résultats

  • Donnez la matière : notes, plan existant, support, énoncé. Sans elle, le skill part d’hypothèses raisonnables, que vous pourrez corriger.
  • Précisez ce qui compte pour vous : durée, public, nombre de questions, sortie voulue. Le reste prend une valeur par défaut.
  • Demandez des retouches ciblées : « raccourcis la partie 3 », « ajoute un exercice ». L’assistant modifie le JSON et refait les fichiers.
  • Relisez avant de diffuser : vous restez l’auteur du document.

Statuts des skills

Chaque skill a un statut, affiché sur sa carte quand il n’est pas recommandé. Il décide de ce que fait la commande d’installation.

Sur la carte Statut Effet
Pas de badge Recommandé Installé par défaut.
Sur demande Disponible Installé seulement si vous le nommez dans SKILLS.
Déprécié Déprécié Gardé là où il est installé, plus installé ailleurs. Passez au skill indiqué en remplacement.
Absent du catalogue Retiré Supprimé de votre poste à la mise à jour suivante.

Dépannage

L’assistant ne voit pas le skill

Ouvrez une nouvelle session : la plupart des assistants ne chargent les skills qu’au démarrage. Relancez la commande et lisez son bilan : il liste les assistants détectés et les dossiers équipés. Le skill doit se trouver dans ~/.agents/skills/<nom>/SKILL.md.

Le skill apparaît deux fois dans Claude Code

Le plugin et une copie coexistent. Relancez la commande : quand le plugin est installé, elle retire ses liens et les anciennes copies de ~/.claude/skills. Dans Claude.ai, désactivez les anciens skills plan-creator, support-creator et qcm-creator.

« Il faut unzip ou python3 »

Installez l’un des deux, par exemple sudo apt install unzip sous Debian ou Ubuntu, puis relancez la commande.

PowerShell refuse la commande

irm … | iex ne dépend pas de la stratégie d’exécution des scripts. Si votre poste est géré par une organisation qui bloque PowerShell, demandez à votre service informatique, ou installez avec Node.js : npx skills add gharel/skills -g.

WSL : « mise à jour automatique impossible »

Votre distribution n’a ni systemd ni cron actif. Ajoutez [boot] puis systemd=true dans /etc/wsl.conf, lancez wsl --shutdown depuis Windows, puis relancez la commande avec SKILLS_AUTO=1.

Un de mes skills a disparu

Il portait le nom d’un de nos skills et a été mis de côté dans ~/.agents/.gharel-skills/sauvegardes. Renommez-le pour garder les deux, ou désinstallez nos skills pour qu’il revienne à sa place.

L’assistant donne du JSON au lieu des fichiers

Il n’exécute pas de code. Activez l’exécution de code (Claude) ou l’interpréteur de code (ChatGPT), ou lancez la commande qu’il vous donne, après pip install python-docx python-pptx openpyxl pillow.
