# Skills UNC

Skills pour les enseignements à l'Université de la Nouvelle-Calédonie : préparation de cours, évaluation des devoirs, suivi des étudiants.

- `notation-etudiants` : corrige et note des TP rendus par mail (GitHub, déploiement) selon un barème, avec un onglet par étudiant (Google Sheets ou `.xlsx`) et une estimation indicative de l'usage de l'IA.

Pour ajouter un skill, copiez `modele/` dans `skills/unc/<nom-du-skill>/` et suivez [AGENTS.md](../../AGENTS.md).
